# 고령운전자 사고 기반 위험회피 안전경로 추천

> ⚠️ **초안 (v0.1.0-draft)** — 캡스톤 최종발표 전 수정 중인 연구용 프로토타입입니다.
> 결과 숫자와 화면은 바뀔 수 있으며, 실제 운전 안내 용도로 만든 것이 아닙니다.

**7조 아이쿵야** · 김예지, 이고은, 이승아 · 지도교수 이병걸

## 무엇을 하나요?
서울 동대문구 ITS 도로망(LINK 4,934개) 위에서, 고령운전자 사고 위험이 높은 도로를 피하는 **안전경로**를 찾아
**일반경로(가장 짧은 길)**와 나란히 비교해 보여 줍니다.

- 위험모델: 로지스틱 회귀 (차로 수, 교차로·신호, 상가 밀집, 매개중심성 등 9개 변수)
- 경로 비용: `Cost = L / L_MEAN + λ × risk_h / H_MEAN`, λ = 0.75
- 회전제한: ITS TURNINFO 좌회전·직진·우회전 금지 반영

## 현재 결과 (초안 기준)
| 항목 | 값 |
|---|---|
| 2025년 사고 예측 (2023~24 학습) | ROC-AUC 0.749, AP 0.299 |
| OD 300쌍, λ = 0.75, 회전제한 반영 | 우회 +6.5%, 누적위험 −15.0%, 2025 사고 도로 통과 −17.9% |

## 실행 방법
```
pip install -r requirements.txt
python check_engine.py            # 엔진 점검
python -m streamlit run app.py    # 웹 실행 → http://localhost:8501
```
파이썬 3.8 이상.

## 폴더 구조
```
app.py, engine.py, check_engine.py   웹 앱과 경로 엔진
data/                                웹에 쓰는 데이터 (도로망·위험점수, 목적지, 회전제한, OD 목록)
analysis/                            분석 스크립트 (재학습, λ 실험, 회전제한 검증, 시설 연결)
analysis/results/                    분석 결과 표
docs/                                설계안·발표 자료 등 문서
```

## 데이터 출처
